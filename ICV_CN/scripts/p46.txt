-license_mode
run_available |
run_and_add | exit |
exit_and_retry
Defines the tool behavior when all multicore licenses are not available
at startup. The default is run_and_add. See User Controls for more
information.
-license_wait_duration
value [d|h|m|s]
Specifies the maximum time the tool waits for licenses to become
available. The default is 0. See User Controls for more information.
-keys key(s) Defines the keys that control environment variable access. Use a
comma-separated list with no spaces to provide multiple keys.
-nlc Turns off license caching.
