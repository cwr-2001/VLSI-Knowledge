Getting Started
     The IC Validator Pattern Library Manager (PLM) is a graphical user interface (GUI)
     that provides an alternate way to build a pattern library for an IC Validator pattern
     matching run instead of using the batch mode for pattern library generation with the
     pattern_learn()function.


     Supported Versions of IC Validator WorkBench
     The Pattern Library Manager communicates with the IC Validator WorkBench tool through
     a socket or port connection.
     IC Validator N-2017.12-SP2 and later versions support IC Validator WorkBench J-2014.06
     and later versions.

     Adding an Edge Tolerance to a Pattern
     The Pattern Library Manager allows you to specify an edge tolerance (constraint) for non-
     uniform fuzzy matching mode. Constraints enable you to match different variations of a
     pattern to the defined pattern. Each edge should not have more than one edge constraint.
     To specify an edge tolerance:
      1. Open a pattern library that contains the patterns for editing.
      2. Select the pattern for editing by clicking on the pattern name. The Tolerance and
         Pattern Property tabs appear in the Pattern Library Manager and the pattern layout is
         displayed in IC WorkBench EV Plus.
      3. Choose an edge to specify the tolerance from the drop-down box. If the edge you
         choose is horizontal, the edge is restricted to move vertically. If the edge you choose is
         vertical, the edge is restricted to move horizontally.
         Note:
             You can use the edge numbers displayed in IC WorkBench EV Plus as a
             reference to identify the edge number.
      4. Click the increase or decrease button to specify an inside and outside limit in
         nanometers. Select Inclusive if the tolerance interval includes the value, as shown in
         Figure 127.

   Figure 127     Adding an Edge Tolerance




      5. Click Add to add the tolerance to the pattern library. Edge tolerances appear on layer
         (9001:0) in IC WorkBench EV Plus.
      6. Choose File > Save to save changes to the pattern library.

Restrictions and Limitations
     The following features are not currently available in the Pattern Library Manager, but are
     supported by the pattern_learn() function in batch mode:
      • Specifies that the IC Validator tool generates a pattern extent based on the user-
        defined ambit value and ambit_mode.
      • Specifies the edge tolerance as user-defined input layers.
      • Specifies the optional region layers.
      • Specifies auto anchoring.
