IC Validator 工具基础包括以下各节：
\begin{itemize}
  \item 在设计流程中使用 IC Validator 工具
  \item IC Validator 命令行选项
  \item 编译器指令（Compiler Directives）
  \item 退出码（Exit Codes）
  \item 内联函数（Inlined Functions）
  \item 分布式处理（Distributed Processing）
  \item Runset 缓存（Runset Caching）
  \item 在 Runset 缓存下使用命令行选项
  \item 层映射（Layer Mapping）
  \item 使用 PXL Runset 加密
\end{itemize}

\section{在设计流程中使用 IC Validator 工具}
\subsection*{Using the IC Validator Tool in Your Design Flow}

所有 IC Validator 运行均基于您的 IC Validator runset 执行。可通过命令行执行、借助 VUE 的交互式执行，或从其他 Synopsys 工具（如 StarRC、IC Compiler）中启动 IC Validator。加载 IC Validator 前须设置两个环境变量：
\begin{itemize}
  \item 将 \cmd{ICV\_HOME\_DIR} 设为 IC Validator 安装目录
  \item 将 \cmd{PATH} 设为包含 \cmd{\$ICV\_HOME\_DIR/bin}
\end{itemize}

要在设计流程中成功运行 IC Validator：
\begin{itemize}
  \item 创建并调试 runset 文件。runset 通常包含：
  \begin{itemize}
    \item 版图数据库相关信息
    \item 通用选项
    \item 层赋值（layer assignments）
    \item 数据库检查（如 snap、grid 检查）
    \item 设计规则检查（DRC）、电气规则检查（ERC）、fill 图案，或版图与原理图对照（LVS）
  \end{itemize}
  \item 对版图数据库运行 IC Validator DRC 与 ERC，对照设计规则文档验证设计。
  \item 使用 IC Validator 错误文件或 VUE 审查并调试 DRC/ERC 结果。
  \item 运行 fill-pattern 生成（含对所填层的基本 DRC 检查）。
  \item 运行 IC Validator LVS。
  \item 使用错误文件或 VUE 审查并调试 LVS 结果。
\end{itemize}

参见附录~A「IC Validator 体系结构」。
\end{seeAlsoBox}

\subsection{在 IC Compiler 中运行 IC Validator}
\subsubsection*{Running the IC Validator Tool Within the IC Compiler Tool}

可在 IC Compiler 内部运行 IC Validator，该流程称为 In-Design 物理验证。相关 IC Compiler 命令包括：
\begin{itemize}
  \item \cmd{signoff\_drc}：使用晶圆厂认证的 IC Validator DRC runset 执行 DRC。
  \item \cmd{signoff\_autofix\_drc}：自动 DRC 修复。流程中 IC Validator 会：
  \begin{itemize}
    \item 执行签核级 DRC；
    \item 生成 route guidance，协助路由器做针对性修复；
    \item 验证路由器完成的修复。
  \end{itemize}
  \item \cmd{signoff\_metal\_fill}：以基于图案（foundry-qualified metal-fill runset）或基于 track（技术文件信息）的模式插入金属与 via fill；fill 图形写入 Milkyway 设计的 FILL view。
  \item \cmd{signoff\_fix\_isolated\_via}：自动修复孤立 via。
  \item \cmd{report\_metal\_density}：计算金属密度与密度梯度并标注到设计上。
\end{itemize}

\begin{noteBox}
在 IC Compiler 中使用前，须确认 IC Validator 能正确解析并运行该 runset。
\end{noteBox}

\begin{seeAlsoBox}
详见 SolvNetPlus 上的 \textit{IC Compiler Implementation User Guide}，或 IC Compiler man 页。
\end{seeAlsoBox}

\subsection{在 IC Compiler II 中运行 IC Validator}
\subsubsection*{Running the IC Validator Tool Within the IC Compiler II Tool}

可在 IC Compiler II 内部运行 IC Validator（In-Design 物理验证）。相关命令包括：
\begin{itemize}
  \item \cmd{signoff\_check\_drc}：使用晶圆厂认证的 IC Validator DRC runset 执行 DRC。
  \item \cmd{signoff\_fix\_drc}：自动 DRC 修复（签核 DRC、生成 route guidance、验证修复）。
  \item \cmd{signoff\_create\_metal\_fill}：图案模式或 track 模式插入金属/via fill；fill 写入 ICC2 输入设计的 design view。
  \item \cmd{signoff\_fix\_isolated\_via}：自动修复孤立 via。
\end{itemize}

\begin{noteBox}
在 IC Compiler II 中使用前，须确认 IC Validator 能正确解析并运行该 runset。
\end{noteBox}

\begin{seeAlsoBox}
详见 SolvNetPlus 上的 \textit{IC Compiler II Implementation User Guide}，或 ICC2 man 页。
\end{seeAlsoBox}

\subsection{与 StarRC 寄生参数提取配合}
\subsubsection*{Running the IC Validator Tool With StarRC Parasitic Extraction}

可在 IC Validator runset 中用下列函数生成供 StarRC 使用的数据：
\begin{itemize}
  \item 寄生提取（PEX）层映射函数：
  \begin{itemize}
    \item \cmd{pex\_conducting\_layer\_map()}
    \item \cmd{pex\_via\_layer\_map()}
    \item \cmd{pex\_marker\_layer\_map()}
    \item \cmd{pex\_remove\_layer\_map()}
    \item \cmd{pex\_viewonly\_layer\_map()}
    \item \cmd{pex\_ignore\_cap\_layer\_map()}

  这些函数将 IC Validator 的 \cmd{polygon\_layer} 对象映射到 StarRC \cmd{TCAD\_GRD\_FILE} 层，以生成层映射文件。

\subsection{从 Custom Compiler 平台运行}
\subsubsection*{Running the IC Validator Tool From the Custom Compiler Platform}

可从 Custom Compiler 的 Verification 菜单或命令行运行 IC Validator 的 DRC 与 LVS。更多信息见 SolvNetPlus 上的 Custom Compiler 文档。

\subsubsection{设置并运行 DRC}
\paragraph*{Setting Up and Running DRC}

在 Custom Compiler 中：
\begin{enumerate}
  \item 在 Layout 窗口选择 \textbf{Verification $>$ DRC $>$ Setup and Run}。
  \item 选择 IC Validator 并指定所需运行参数。
  \item 点击 \textbf{Apply} 或 \textbf{OK} 运行。
\end{enumerate}

\begin{noteBox}
勾选 \textbf{View Output} 可打开 Custom Compiler Text Viewer，以标签页查看 runset、结果、错误与运行日志。
\end{noteBox}

若参数已在 Setup and Run 中设好，可选 \textbf{Verification $>$ DRC $>$ Run}。

启动 VUE 调试：
\begin{itemize}
  \item 运行后：\textbf{Verification $>$ DRC $>$ Debug}
  \item 若 Setup 未设为 ICV：先执行 \cmd{db::setPrefValue xtDRCTool -value icv}，再选 Debug
\end{itemize}

打开 Text Viewer（访问 runset、\cmd{cell.RESULTS}、\cmd{cell.LAYOUT\_ERRORS}、\cmd{stdout.drc.log}）：
\textbf{Verification $>$ DRC $>$ View Output}。

\subsubsection{设置并运行 LVS}
\paragraph*{Setting Up and Running LVS}

\begin{enumerate}
  \item 在 Layout 或 Schematic 窗口选择 \textbf{Verification $>$ LVS $>$ Setup and Run}。
  \item 选择 IC Validator 并指定参数。
  \item 点击 \textbf{Apply} 或 \textbf{OK}。
\end{enumerate}

\begin{noteBox}
勾选 \textbf{View Output} 可在 Text Viewer 中查看 runset、结果、错误与日志。
\end{noteBox}

参数已设好时选 \textbf{Verification $>$ LVS $>$ Run}。

VUE：\textbf{Verification $>$ LVS $>$ Debug}；若 Setup 未设为 ICV，先 \cmd{db::setPrefValue xtLVSTool -value icv}。

Text Viewer（runset、\cmd{cell.RESULTS}、\cmd{cell.LAYOUT\_ERRORS}、\cmd{cell.LVS\_ERRORS}、\cmd{stdout.lvs.log}）：
\textbf{Verification $>$ LVS $>$ View Output}。

\section{IC Validator 命令行选项}
\subsection*{IC Validator Command-Line Options}

命令行语法为：
\begin{lstlisting}
icv [command-line-options] [runsetfile]
\end{lstlisting}

其中 \cmd{runsetfile} 是用 PXL 编写的指令集，告知 IC Validator 如何执行检查。多数情况下需要 runset；例外包括比较两个网表，或向运行中的作业添加/移除主机等。

选项按用途分为：Common、Host Configuration、Runset Configuration、DRC、LVS/PERC、Explorer、Input Database、Output、Debug、Optimization Controls、Licensing、General。
