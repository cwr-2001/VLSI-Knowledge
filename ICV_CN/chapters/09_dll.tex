% 第 9 章 Dynamic-Link Library Support
\bichapter{动态链接库支持}{Dynamic-Link Library Support}
\label{chap:dll}

本章说明如何使用 IC Validator 工具的动态链接（dynamic-link）功能。

动态链接功能专用于器件抽取（device extraction）。该功能允许将测量数据传递给 IC Validator 工具外部的 C 库，再将 C 库的计算结果返回工具。这些 C 库必须是共享（动态）库。
动态链接库支持包括以下各节：
\begin{itemize}
  \item 动态链接函数
  \item 使用动态链接函数
\end{itemize}

% ============================================================
\section{动态链接函数}
\subsection*{Dynamic-Link Functions}

下列 IC Validator 函数支持动态链接库功能：
\begin{itemize}
  \item \cmd{dev\_dlink\_library\_close()} 函数
  \item \cmd{dev\_dlink\_library\_open()} 函数
  \item \cmd{dev\_dlink()} 实用函数
  \item \cmd{dev\_dlink\_library()} 实用函数
  \item 所有器件配置函数（例如 \cmd{capacitor()}）的 \cmd{dlink\_libraries} 参数
\end{itemize}

% ============================================================
\section{使用动态链接函数}
\subsection*{Using the Dynamic-Link Functions}

使用动态链接的步骤如下：
\begin{enumerate}
  \item 在 IC Validator runset 中：
  \begin{enumerate}
    \item 使用 \cmd{dev\_dlink\_library\_open()} 打开 C 库。
    \item 在器件配置函数中通过 \cmd{dlink\_libraries} 参数指定库句柄。
    \item 使用 \cmd{dev\_dlink\_library\_close()} 关闭库。
  \end{enumerate}
  例如：
\begin{lstlisting}[style=pxl]
dlink_handle = dev_dlink_library_open("library_name");

nmos(
   property_function=my_mos_func,
   dlink_libraries = {dlink_handle}
);

dev_dlink_library_close(dlink_handle);
\end{lstlisting}

  \item 使用实用函数定义器件测量数据的计算。动态链接远端函数通常按如下方式组织：
\begin{lstlisting}[style=pxl]
my_mos_func : function(void) returning void {
   //(1) 使用器件实用函数获取器件测量数据
   //(2) 将测量数据编码为一维数组
   //(3) 使用 dev_dlink_library() 实用函数获取动态链接库文件句柄
   //(4) 使用 dev_dlink() 实用函数调用用户定义的动态链接函数，
   //    并将必要信息传入外部共享库
         IC Validator data
}
\end{lstlisting}

  \item 用户用 C 语言编写的包装函数典型流程如下：
\begin{lstlisting}[style=pxl]
customer_wrapper_function() {
   //(1) 将测量数据解码为客户格式
   //(2) 根据字符串参数决定函数指针
   //(3) 调用内部函数
   //(4) 返回计算结果
}
\end{lstlisting}
\end{enumerate}
