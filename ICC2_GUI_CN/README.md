基于 Synopsys *IC Compiler II Graphical User Interface User Guide*（**V-2023.12**, December 2023）的非官方个人学习译本。版式与 `ICC2_CN` 一致。

原文版权归 Synopsys, Inc. 所有。本译本仅供个人学习，不得商业传播。命令名、选项名、菜单名保持英文。插图从原版 PDF 截取。

## 编译

```bat
cd "d:\IC Design\VLSI\ICC2_GUI_CN"
build.bat
```

需要 XeLaTeX 与 Windows 字体 SimSun / Microsoft YaHei / FangSong。
