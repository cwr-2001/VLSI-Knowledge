Using GUI Assistant Tools
The IC Compiler II GUI provides many assistants, such as the Task Assistant, Net 
Assistant, Pin Assistant, and Design Assistant to help you manage different objects in your 
design. For example, the Task Assistant consolidates commonly used commands into 
different flows to support design planning, timing analysis, placement, and other flows. The 
GUI Assistant Tools can simplify the design process.

Listing and Selecting Objects
The Design Assistant supports a search box for listing cell, net, pin, and topology objects. 
To populate the list of objects,
1. Click the Cells, Nets, Pins, or Topologies tab.
The Topologies tab is available only when you select Get Topology Plans from the 
context menu, or use the menu commands View > Topology Plans of selected or 
View > New Topologies.
2. Enter a search term in the box.
You can specify a full string, a sub string, a wildcard expression, a Tcl command, or 
a Tcl variable. For example, specify any of the following entries in the search box to 
match the cells u0_0, u0_1, u0_2, u0_3 (and possibly other cells).
3. Press Enter.
•
Strings only: 'u', 'u0' or 'u0_'
•
Wildcards: 'u0_*', 'u0_?'
•
A Tcl command: get_cells "*" -filter name=~"u0*"

Performing Related Tasks
Each tab in the Design Assistant window supports a context menu that displays the 
different tasks you can perform on the list of objects. Move the pointer over an entry in the 
list and click the right mouse button to view the context menu. The context menu displays 
tasks related to the selected object. For example, if you open the context menu in the 
Cells tab, the context menu displays the Get Nets, Get Hierarchical Nets, Get Pins, and 
Create Bounds tasks for the selected object. Click the item in the context menu to perform 
the task. After you select the task from the context menu, the tool opens the appropriate 
tab and displays the information. Another example is, when you open the context menu on 
the Topologies tab, the context menu displays the Get Nets task for the selected object. 
To view or hide topology plans, perform the Show Topology Plans (hierarchical) or Hide 
Topology Plans task, respectively.
Note that you can perform the same related actions by choosing it from the menu bar. For 
example, to display nets for the selected item in the Cells tab, choose Cells > Get Nets 
from the Design Assistant menu bar. The items in the menu bar change as you select 
different tabs in the Design Assistant.
You can also use the context menu to highlight an object, zoom in to view the object, write 
a Tcl command to a script file to select the object, and perform other tasks. Click the item 
in the context menu to perform the action.

Using the Constraints Editor
Use the Constraints Editor panel to display and modify net, topology, and shaping 
constraints. Net constraints include nondefault routing rules and routing corridors 
associated with objects selected in the Nets tab. Shaping constraints include target 
location, parent object, boundary, utilization, and so on, which are set by using the 
create_shaping_constraint command. Topology constraints include topology nodes, 
edges, and repeaters associated with the topology plans that are selected on the 
Topologies tab.
To use the panel to review and modify all constraints,
1. Choose View > Toolbars > Constraints Editor from the Design Assistant menu or 
click the Constraints Editor tab.
2. Select an object in Nets, Topologies, or Shapeable view.
3. Click an object name in the table.
4. Click the constraint type in the constraint list to view the properties for that constraint.
5. (Optional) Modify the properties for the constraint in the properties editor table.
6. (Optional) Right-click over the constraint type in the constraint table and choose Select, 
Select Owners, or Delete to select or delete the constraint type.
7. (Optional) Click the Options button (the gear icon) to turn on the Synchronize Global 
Selection mode and allow a 2-way synchronization of global and Constraints Editor 
selections.
However, you cannot have both options in the Design Assistant view and Constraints 
Editor palette enabled at the same time; they are mutually exclusive.
To use the panel to review and modify net constraints,
1. Choose View > Shapeable Objects from the Design Assistant menu.
2. Choose View > Toolbars > Constraints Editor from the Design Assistant menu or 
click the Constraints Editor tab.
3. Click an object name in the table.
4. Click the [+] symbol in the constraint list to view the properties for that constraint.
5. (Optional) Modify the properties for the constraint in the properties editor table.
6. (Optional) Click the right mouse button over the constraint type in the constraint table 
and choose Select, Select Owners, or Delete to select or delete the constraint type.

design. Start the Netlist Tracer by choosing View > Assistants > Netlist Tracer from the 
menu. Use the Netlist Tracer to trace a net by traversing its path through the design. Begin 
by selecting a cell, net, pin, or port from which to trace. You can traverse the path of nets 
that connect to the object, highlight the path, and zoom in on related cells, nets, and pins. 
As you trace the path, the Netlist Tracer displays flylines between the current object and
