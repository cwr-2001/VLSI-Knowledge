Creating Routes
The IC Compiler II GUI provides interactive and programmatic interfaces to quickly 
and easily create routes. Use the Create Route tool to route one or more nets or 
bundles between pins, ports, and other route shapes in the design. Similar to the Create 
Route tool, use the Create RDL tool to route single nets to create orthogonal and 45-
degree routes on the redistribution layer or other metal layers. The create_trunk, 
create_trunk_pin_to_pin, and create_trunk_pin_to_trunk commands create route 
segments on specified nets based on command line options.

Creating Routes Interactively
The Create Route tool enables you to interactively route one or more nets or bundles. 
Options to the tool specify how the routes are created. The tool supports blockage 
avoidance and DRC feedback to help create high quality, violation-free routes and 
connection. Snapping, auto-alignment, and auto-welding are provided to quickly and 
easily connect new routes to pins or preexisting routes. Bundle routing is supported for the 
simultaneous routing of several signals at one time.

Specifying Other Welding and Connection Options
The Create Route tool supports additional options for specifying the connection to existing 
routes or pins.
•
Ignore pin access direction: When selected, the tool automatically connects routes to 
pins regardless of pin access direction. By default, pin access direction is considered.
•
Skip PG nets: When selected, avoid creating a connection to a PG net. This option is 
used to skip connections to ground nets when the nets are used for net shielding.
•
Honor via to via spacing: When selected, the tool honors same-net via-to-via spacing 
rules.
•
No via on pin: Avoids inserting a via when making a connection to a pin.
•
Adjust to pin width: When selected, the tool sets the width of the route to the width of 
the pin, if the wire width is less than the pin width. By default, this option is deselected 
and the width of the wire is specified in the toolbar. Note that if the wire width is greater 
than the pin width, the pin width is used for the wire width.
•
Align with pin center: When deselected, the tool aligns the connecting wire with the 
nearest parallel pin edge or extends the wire within the parallel pin edge boundaries. 
Track snapping and spacing requirements might affect the final wire position. By 
default, this option is selected and the tool aligns the route with the center of the 
bounding box for the pin if possible. When the pin is wider than the connecting wire, the 
tool might shift the wire off-center to honor track snapping and spacing settings.

Recording and Replaying Create Route Actions
The Create Route and Create RDL tools support a record feature that captures the mouse 
actions used to create a route and saves them to the Script Editor. The script can be 
saved to disk and run at a later time. Alternatively, the script can be run directly from the 
Script Editor. The record feature can be configured with options to tolerate small changes 
in the position of the pins; this allows you to re-create a route after minor design changes.
To create a route and enable recording,
1. Start the Create Route tool by choosing Create > Route, clicking the Create Route 
button (
), or pressing Shift+R.
Start the Create RDL tool by choosing Create > RDL or by clicking the Create RDL 
button (
).
2. (Optional) Set any necessary routing options in the toolbar.
3. (Optional) If the pin or segment coordinates in the route are expected to change when 
the route is re-created, click the More button and enable the Relative to nets option in 
the Log/replay coordinates section.
When this option is enabled, the tool captures coordinates relative to the bounding box 
for the entire route, rather than capturing absolute coordinates. This option is useful if 
the script is applied to create routes in a different area of the design.
4. Click the Record button (
) on the Create Route tool toolbar.
5. Create the route by clicking the startpoint, creating net segments, and terminating the 
route.
6. When the route is complete, open the Script Editor and click the Save As button (
) 
to save the script to a file.

Creating Route Trunks With Tcl Commands or GUI
The IC Compiler II GUI supports Tcl commands to create route trunks for specified 
nets and bundles. Use the create_trunk, create_trunk_shared_track, 
create_trunk_pin_to_trunk, create_trunk_pin_to_pin, and 
create_trunk_topology commands to create route trunk segments and connections as 
described in this topic.
Creating Route Segments in One Direction
To create route trunks in one direction on a single metal layer, use the create_trunk 
command as follows:
icc2_shell> set nets [get_nets {net1 net2 net3 net4}]
icc2_shell> create_trunk -nets $nets -layer M3 \
   -gravity percentage -percentage 25
The command creates a route segment for each net or bundle specified by the -nets 
option. In this example, the -gravity percentage option specifies how the route 
segments are aligned with the bounding box for the nets. The -percentage 25 option 
specifies that the first route segment is placed at the bottom edge of the bounding box plus 
25 percent of the height of the bounding box. The following figure shows different routing 
results for percentage values of 25, 50, and 75.

Estimating Point-to-Point Resistance
To calculate the resistance between two points (pins or ports) in the current design, use 
the estimate_resistance command.
In the command, you can specify a starting point and an endpoint in various ways:
•
By using the -net option – This option works only for a net with only two pins or ports, 
where each pin or port has a single terminal.
•
By using the -pins option – This option works for a net with more than two pins or 
ports. Ensure that you specify the exact pins and ports in the command so that it can 
measure the resistance between the specified points.
•
By using the -shapes option – This option works for measuring the resistance for 
arbitrary segments that are set in a complex structure. For example, the connection of 
a PG pin with a mesh. However, ensure that you avoid passing the whole mesh as a 
set of shapes for performance reasons.
When you use the -shapes option, specify the starting point, its layer, the ending point, 
and its layer.
Use the -quiet and -verbose options to either suppress the messages or print them in 
detail on the console, respectively.
The following command estimates resistance between the VDD pins on the specified cells:
icc2_shell> estimate_resistance -pins "INV_279/VDD U27/VDD"
