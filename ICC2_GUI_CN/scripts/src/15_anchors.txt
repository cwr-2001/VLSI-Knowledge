Creating Anchors
Anchors help you to anchor one design object to another. When you anchor an object, that 
object is the dependent object and the object that the dependent object is anchored to is 
the anchor object. When you move an anchor object, any dependent object anchored to it 
also moves with the anchor object. When you move a dependent object, it snaps back to 
its anchored location.
To create an anchor, in the IC Compiler II GUI, choose Create > Anchor. The anchor 
creation tool displays. The following image shows the anchor creation tool:
The anchor creation tool provides the following options:
•
Anchor type - To specify how the object is anchored. You can choose to anchor in X or 
Y co-ordinates or both X and Y coordinates.
•
Dependent - To specify the dependent object
•
Anchor - To specify the anchor object
•
Position Reference - To specify the position reference for dependent and anchor 
objects
•
Offset - To specify X and Y offset values from the dependent object to the anchor 
object. Default is {0,0}
You can also create anchors down the hierarchy. To create an anchor in hierarchy, go 
to the Layout settings panel and enable deep selection and increase the view level. 
After setting these requirements, you can pick dependent and anchor objects within the 
hierarchy.
