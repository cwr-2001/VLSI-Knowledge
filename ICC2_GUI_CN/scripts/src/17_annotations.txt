Creating Persistent Annotations
To create persistent annotations (shapes, text, and symbols) that are saved in the 
database, use the create_annotation_shape, create_annotation_text, and 
create_annotation_symbol commands. Alternatively, use the Create Annotation tool 
(Create > Annotation) to create them.
When you select the Attach check box in the Create Annotation tool, the objects under 
the mouse pointer are preselected. When you click over such an object, the annotation is 
attached or anchored to that object. When you move the object, the annotation follows it.

Creating Annotation Shapes
Use the create_annotation_shape command to create annotation shapes of types 
circle, line, rectangle, and polygon with optional text labels. For more information about 
this command, see the man page.
Alternatively, use the Create Annotation tool to create an annotation shape. You can 
specify the type (circle, rectangle, and others), style (fill pattern, line width, color, and 
others), label, the orientation of the label (R0, MY, and others), and others by using this 
tool.
The following examples create different types of annotation shapes by using the

Creating Annotation Symbols
Use the create_annotation_symbol command to create annotation symbols of types 
cross, diamond, square, triangle, custom symbols, and symbols that are zoom-dependent 
(fit_symbol). For a custom symbol, you must specify the input file in SVG format by 
using the -file option. For more information about this command, see the man page.
Alternatively, use the Create Annotation tool to create an annotation symbol. You can 
specify the type (symbol), its type, size, style (fill pattern, line width, color, and others), 
orientation of the symbol, and others by using this tool.
The fit_symbol type of annotation is built out of predefined shapes (such as, cross, 
diamond, square, triangle, or custom). It renders bigger, when you zoom in and 
smaller, when you zoom out. In contrast, the symbol and text annotations are zoom-
independent, and their sizes are defined by the symbol size in pixels and the font size 
in points, correspondingly. Use the fit_symbol annotations for symbols that need to be 
comparative in size with the annotated physical design objects.
The following examples create different types of annotation symbols by using the 
create_annotation_symbol command.

icc2_shell> create_annotation_symbol -type custom \

To add a custom symbol (for example, buffer, inverter, OR gate, or a star) from the 
examples directory:
1. (Optional) Use the gui.annotation_symbol_dir application option to define 
the location of the annotation symbol files. By default, it points to the examples 
directory. If needed, change this option to reference any specific directory that 
contains your SVG files.
icc2_shell> set_app_options -name gui.annotation_symbol_dir \
   -value $synopsys_root/auxx/gui/nwtn/svg_examples
2. Choose Create > Annotation.
3. From the Symbol drop-down list, choose custom.
4. From the User symbol drop-down list, choose a symbol.

Creating Annotation Text
Use the create_annotation_text command to create annotation text.
Alternatively, use the Create Annotation tool to create an annotation text. You can specify 
the type (text), style (fill pattern, line width, color, and others), label, the orientation of the 
label (R0, MY, and others), and others by using this tool. The Text field supports multi-line 
text.
The following examples create different annotation text by using the 
create_annotation_text command.
•
Add a text annotation that is oriented horizontally.
icc2_shell> create_annotation_text -text Text1 \
   -origin {969.370 1204.625} -name annoText1 \
   -font_size 12 -color red -horizontal_alignment center \
   -vertical_alignment middle
