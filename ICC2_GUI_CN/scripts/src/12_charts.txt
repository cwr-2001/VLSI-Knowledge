Creating Charts
The IC Compiler II tool contains a comprehensive plot generation utility you can use to 
generate interactive plots based on design, layout, and other data. See the following topics 
for more information:
•
Creating a Model
•
Creating a Plot
Creating a Model
To create a chart, begin by importing the chart data from a comma-separated values 
(CSV) file to create a model. Use the gui_create_charts_model command to read the 
CSV and save the information as a Tcl variable.
The following example writes out a simple CSV file containing the instance name, 
number of pins, and area for each macro in the design. The gui_create_charts_model 
command loads the CSV file and creates a chart model.
set macros [get_cells -hier -filter "design_type==macro"]
set csv_file /tmp/count_area.csv
echo "macro_inst,count,area" > $csv_file
foreach_in_collection c $macros {
  echo [get_object_name $c],[get_attribute $c 
 number_of_pins],[get_attribute $c area] >> $csv_file
}
set model [gui_create_charts_model -csv $csv_file -first_line_header ]
Note that the gui_create_charts_model command automatically derives the data type 
for each column of data.
Alternatively, you can import the CSV file by using the GUI. Click the Charts tab in the 
View Settings panel, then click the Models tab. Click the Create button to open the 
Load Model dialog box. Enter the file name, select options to specify the header. The 
tool displays a preview of the data as shown in the following figure. Click OK to create the 
model.

In addition to using CSV, you can create a model directly from a collection or a Tcl array. 
For example:
set selection [get_nets]
set model1 [gui_create_charts_model -clct $selection -columns {name 
 dr_x_length dr_y_length}]
 
set data [list \
[list State {Under 5 Years} {5 to 13 Years} {14 to 17 Years} {18 to 24 
 Years} {25 to 44 Years} {45 to 64 Years} {65 Years and Over}] \
[list CA 2704659 4499890 2159981 3853788 10604510 8819342 4114496] \

Checking the Model
After creating the model, check the model in the GUI by clicking the Charts tab in the 
View Settings panel. Click the Models tab to show the list of models created with the 
gui_create_charts_model command.
To view details for a model, including column names, data types, and other properties, 
click the model in the table and click the Edit button to show the table of data. Click each 
column to show the column name, data type, and other attributes for the data column. To 
change the properties for the column, select an entry in the Column Data section and 
click Apply.

Adding or Deleting Data From the Model
After importing the CSV file, you can modify the data type by adding columns, deleting 
columns, and performing other operations with the gui_change_charts_model command. 
The following example adds a new column called “double_count” which is twice the value 
of the data in column(1).
gui_change_charts_model -model $model -add \
   -expr {column(1) + column(1)} -header double_count

Creating a Plot
After importing the CSV file to create a model, you can create a plot to view the data. Use 
the gui_create_charts_plot command to create a bar chart, distribution plot, XY chart, 
and so on.
The following example writes out a CSV file that contains the pin count and area for four 
macros in the design. The gui_create_charts_plot command creates the initial plot 
based on the CSV file contents. Next, the plot is converted to a horizontal bar chart by 
choosing Horizontal from the context menu. The data table is displayed by choosing Show 
Table from the context menu.
# Create the Charts window
set view [gui_create_window -type Charts]
 
# Specify the macros and output CSV file
set macros [get_cells { cmem0/idata0_2/x0_t0 cmem0/dtags1_1/x0_t0
                        rf0/x0/t_bl cmem0/itags0_3/x0_t0 }]
set csv_file count_area.csv
 
# Write out the CSV file
echo "macro_inst,count,area" > $csv_file
foreach_in_collection c $macros {
  echo [get_object_name $c],\
[get_attribute $c number_of_pins],\
[get_attribute $c area] >> $csv_file
}
 
# Create the model
set model [gui_create_charts_model -csv $csv_file -first_line_header]
 
# Create the bar chart from the model
set plot [gui_create_charts_plot -view $view -type barchart \
   -model $model -columns {{name 0} {value {1}}}]

Customizing a Plot
You can modify the plot to:
•
Customize the appearance using the View Settings > Properties or the 
gui_set_charts_property command
•
Add annotations using View Settings > Annotations or the 
gui_create_charts_*_annotation commands
•
Lay out multiple plots in view using View Settings > Plots, or the 
gui_place_charts_plots and gui_group_charts_plots commands
•
Run custom Tcl procedures on user interaction using the 
gui_connect_charts_signal command
