After you have compiled your design, you can review timing analysis results by using the 
GUI.
To gather timing analysis results using the GUI,
1. Use the Timing Analysis window to get the endpoint summary information.
In the main menu bar, select Window > Timing Analysis Window.

Displaying the Timing Analysis Endpoint Summary
The Timing Analysis Window shows the timing summary of the current design. This should 
match the results of running the report_qor -summary command.
Before using this information for analysis, make sure that the timing is up-to-date. 
The green check mark indicates that the timing is up-to-date. If it is not, a red mark is 
displayed. To update the timing, click the Update button (see Figure 124).

Saving and Loading Timing Path Data
To save the selected timing path collections to disk, click the Write button at the bottom 
of the Timing Analysis window (Path Collections tab). If parametric on-chip variation 
(POCV) is enabled when you save the timing path collection, the POCV data is saved with 
the timing paths. To load previously saved timing path data, click the Read button at the 
bottom of the Timing Analysis window (Path Collections tab). If the POCV is enabled and 
the file contains POCV data, the POCV data is restored with the timing paths.
Analyzing Timing Path Collections
You can use the path analyzer to analyze a collection of timing paths and determine where 
timing failures occur in the design. The path analyzer analyzes the paths using a rule 
that you specify, categorizes them based on available attribute values, and displays the 
categories in a color-coded treemap view. You can select a predefined category rule or 
define a custom category rule. You can also add subcategories.

To open the path analyzer, choose View > New Path Analyzer in the timing analysis 
window.
You must load and categorize the timing paths before you can view them in the treemap.
To load a collection of timing paths,
1. Specify the collection in the Collections box.
You can enter the collection name or a Tcl command that creates the collection.
2. Click Apply.
To categorize the timing paths,
1. Select All in the categories tree.
2. Click the Create button.
The Create Category dialog box appears.
3. Select a rule.
4. Click OK.
You can load one or more collections of timing paths from the same design.
After categorizing the paths, select All at the top of the category tree and reposition the 
slider on the right to view the categories in the treemap view. The All category contains all 
the paths that you have loaded into the path analyzer.
