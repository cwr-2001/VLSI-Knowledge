Viewing Schematics
The IC Compiler II tool supports design schematics to examine logic elements (blocks and 
gates) in a design. A design schematic displays a graphic representation of a hierarchical 
cell in a schematic view. You can move up or down in the design hierarchy to view the 
schematic for each design in the hierarchy.

Schematic View
To view a schematic, use one of the following methods:
•
Choose View > Schematic View in the main menu bar or in the Hierarchy Browser
•
Click the 
 button on the toolbar
Use schematic views to visually analyze timing and logic for use in further optimization 
operations. For example, you can
•
View graphic representations of the logic elements (blocks and gates) in a design or 
subdesign
•
Examine timing problems by focusing on critical paths in your logic design
To customize a schematic view, use the View Settings panel located in the tab on the right 
side of the tool.

WordView in the Schematic View
WordView models wide combination logic gates that can be easily represented in 
schematic views. In the GUI, WordView allows for a cleaner schematic view of unmapped 
logic. The tool uses a wide logic gate instead of cascaded gates, and it shows bused 
instances in a collapsed representation. For purposes of area estimation, WordView more 
accurately models the original logic represented in the RTL.
WordView uses a WVGTECH library as opposed to a GTECH library. In order for the tool 
to infer these gates, you must have a WVGTECH library available.
When you are in the Schematic View, the GUI uses WordView gates to display:
•
Bused instances
•
Wide gates
•
Operators
•
Bused registers to multibit cells
The example in Figure 117 shows a collapsed bused instance. In this case, it is a 
WVGTECH_AND gate with four inputs pins.
Figure 117
Collapsed View of a Bused Instance
You can expand the WVGTECH gate by selecting it and opening the context menu 
and selecting the Expand > Selected Objects option. By default, bused instances are 
displayed in the GUI with a dashed border (see Figure 118). Bused nets are shown with 
one thick, blue line and bus inverters have the same logic symbol with a thick, green line. 
You can change the view from scalar to bus representation for a bused object using the 
Schematic View's context menu and select the Expand or Collapse menu options.

Annotating Attributes on the Schematic View
To aid in debugging, you can annotate attributes on cells, pins, and ports in the schematic 
view. To do this, select the attribute to annotate in the Annotation Attributes section of the 
Settings tab on the View Settings panel, as shown in Figure 121. You can annotate only a 
single attribute on an object.

Adding Pin Markers to the Schematic View
To highlight content in the schematic view, you can add markers on pins in the schematic 
view. When you add a marker, you can select the following characteristics of the marker:
•
Shape: diamond or dot
•
Color: yellow, orange, or red
To add a marker to a pin, right-click the pin, and choose Pin Markers > Set > 
marker_type, where marker_type is one of Yellow Diamond, Orange Diamond, Red 
Diamond, Yellow Dot, Orange Dot, or Red Dot. Figure 123 shows the interface for adding 
pin markers.
