Working With Manufacturing Objects
The IC Compiler II GUI enables you to view, select, and edit the following manufacturing 
objects that are in your design. These objects are called manufacturing objects because 
they play a role in the manufacturing of a semiconductor chip.
•
Assembly die - the physical die after being cut from a wafer.
•
Sealring - the rectangular portion of the wafer, which is larger than the die boundary. It 
protects the die from mechanical damage.
•
Stitching zone (Kerf) - the width of material removed during the cutting of a wafer to 
form a die.

Selecting a Manufacturing Object
The IC Compiler II tool enables you to select a manufacturing object
•
From the Layout view by clicking on the object
•
From the context-sensitive menu by choosing the Related Manufacturing Shapes 
menu
•
From the Select by Name toolbar
When you hover over a manufacturing object, the tooltip displays information about that 
object. For example,
In the Layout view, you control the visibility and selection of a manufacturing object by 
using the View Settings panel.

Editing a Manufacturing Object
You can stretch, add, or cut a manufacturing object from the IC Compiler II GUI. To 
perform any of these operations,
1. In the Layout view, select the object.
2. Use the editing tools from the Edit menu.
For more information about how to edit objects in the Layout view, see the Editing the 
Physical Layout topic.
