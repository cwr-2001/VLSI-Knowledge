Creating Cell
You can create cells (prototype blocks or complete dies) from the IC Compiler II GUI. 
Using the GUI, you can also create hierarchical blocks without using the edit-in-place 
feature.
To create a cell, in the IC Compiler II GUI, choose Create > Cell. Alternatively, use the 
create cell mouse tool. The Create cell tool appears.
The following image shows the Create cell tool.
Creating a Hierarchical Block
To create a hierarchical instance or block:
1. Enable deep selection and increase the Level in the Layout settings panel.
2. Choose Create > Cell. The Create Cell tool appears.
3. Click New Block Cell icon to create a new block or select Add Block Cell icon to create 
an instance of an existing block.
4. Specify the library in the Library field.
