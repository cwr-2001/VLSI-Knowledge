% 附录 C Basic Commands
\bichapter{基本命令}{Basic Commands}
\label{app:commands}

本附录列出综合用基本 \cmd{de\_shell} 命令，并为每条命令提供简要说明。命令按下列主题分组：
\begin{itemize}
  \item 定义设计规则的命令
  \item 定义设计环境的命令
  \item 设置设计约束的命令
  \item 分析并解决设计问题的命令
\end{itemize}

在每一节内，命令按字母顺序列出。

% ============================================================
\section{定义设计规则的命令}
\subsection*{Commands for Defining Design Rules}

定义设计规则的命令为：
\begin{description}[style=nextline,leftmargin=3.2cm,font=\ttfamily\normalsize]
  \item[set\_max\_capacitance]
        为连接到指定 port 的 net，或为设计中的所有 net，设置 maximum capacitance。
  \item[set\_max\_fanout]
        为 output port 设置 expected fanout load value。
  \item[set\_max\_transition]
        为连接到指定 port 的 net，或为设计中的所有 net，设置 maximum transition time。
  \item[set\_min\_capacitance]
        为附着到指定端口的网，或设计中的所有网，设置最小电容。
\end{description}

% ============================================================
\section{定义设计环境的命令}
\subsection*{Commands for Defining Design Environments}

定义设计环境的命令为：
\begin{description}[style=nextline,leftmargin=3.2cm,font=\ttfamily\normalsize]
  \item[set\_drive]
        设置输入或 inout 端口的驱动值。\cmd{set\_drive} 命令已被 \cmd{set\_driving\_cell} 命令取代。
  \item[set\_driving\_cell]
        在 input 或 inout port 上设置 attribute，指定驱动这些 port 的 library cell 或 library pin。
        该命令将 library pin 与 input port 关联，使 delay calculator 能够准确建模 external driver 的 drive capability。
  \item[set\_fanout\_load]
        定义输出端口上的外部扇出负载值。
  \item[set\_load]
        定义输入与输出端口以及网上的外部负载值。
  \item[set\_operating\_conditions]
        定义当前设计的工作条件。
\end{description}

\section{设置设计约束的命令}
\subsection*{Commands for Setting Design Constraints}

设置设计约束的基本命令为：
\begin{description}[style=nextline,leftmargin=3.2cm,font=\ttfamily\normalsize]
  \item[create\_clock]
        在当前设计中创建时钟对象并定义其波形。
  \item[set\_clock\_latency, set\_clock\_uncertainty, set\_propagated\_clock, set\_clock\_transition]
        在 clock object 或 flip-flop clock pin 上设置 clock attribute。
  \item[set\_input\_delay]
        相对于时钟信号在引脚或输入端口上设置输入延时。
  \item[set\_max\_area]
        指定当前设计的最大面积。
  \item[set\_output\_delay]
        相对于时钟信号在引脚或输出端口上设置输出延时。
\end{description}

设置设计约束的高级命令为：
\begin{description}[style=nextline,leftmargin=3.2cm,font=\ttfamily\normalsize]
  \item[group\_path]
        对一组 path 或 endpoint 分组，以便进行 cost-function 计算。该命令用于创建 path group、向现有 group 添加 path，或更改现有 group 的 weight。
  \item[set\_false\_path]
        将指定点之间的 path 标记为 false path，并从 timing analysis 中排除所选 path。
  \item[set\_max\_delay]
        为当前设计中所选路径指定最大延时目标。
  \item[set\_min\_delay]
        为当前设计中所选路径指定最小延时目标。
  \item[set\_multicycle\_path]
        允许指定 timing path 使用超过一个 clock period 的时间。
\end{description}

\section{分析并解决设计问题的命令}
\subsection*{Commands for Analyzing and Resolving Design Problems}

分析并解决设计问题的命令为：
\begin{description}[style=nextline,leftmargin=3.5cm,font=\ttfamily\normalsize]
  \item[all\_connected]
        列出网上的所有扇出。
  \item[all\_registers]
        列出设计中的 sequential element 或 pin。
  \item[check\_design]
        检查当前设计内部表示的一致性，并酌情发出错误与警告消息。
  \item[check\_timing]
        检查施加于 current design 的 timing attribute。
  \item[get\_attribute]
        报告指定属性的值。
  \item[link]
        定位设计中每个单元的引用。
  \item[report\_area]
        提供当前设计的面积信息与统计。
  \item[report\_attribute]
        列出所选 object 的 attribute 及其值。object 可以是 cell、net、pin、port、instance 或 design。
  \item[report\_cell]
        列出当前设计中的单元及其单元属性。
  \item[report\_clock]
        显示当前设计上与时钟相关的信息。
  \item[report\_constraint]
        列出当前设计上的约束及其代价、权重与加权代价。
  \item[report\_delay\_calculation]
        报告延时弧计算的细节。
  \item[report\_design]
        显示为当前设计定义的工作条件、线负载模型与模式、时序范围、内部输入与输出，以及禁用的时序弧。
  \item[report\_design\_mismatch]
        报告为使 design 能够 link 而被绕过的 design mismatch。
  \item[report\_hierarchy]
        列出当前设计的子设计。
  \item[report\_missing\_constraints]
        报告当前设计中缺失的约束。
  \item[report\_net]
        若已设置当前实例，则显示该实例所属设计的网信息；否则显示当前设计的网信息。
  \item[report\_path\_group]
        列出当前设计中所有时序路径组。
  \item[report\_port]
        列出当前设计中关于端口的信息。
  \item[report\_qor]
        显示当前设计的结果质量信息及其他统计。
  \item[report\_resources]
        显示关于资源实现的信息。
  \item[report\_timing]
        列出当前设计的时序信息。
  \item[report\_timing\_requirements]
        列出时序路径要求及相关信息。
  \item[report\_transitive\_fanin]
        列出当前实例所选引脚、网或端口的扇入逻辑。
  \item[report\_transitive\_fanout]
        列出当前实例所选引脚、网或端口的扇出逻辑。
\end{description}
