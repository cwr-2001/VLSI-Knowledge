\noindent\textit{About This User Guide}

Synopsys PrimeTime Suite 在单一集成环境中提供全面的全芯片静态时序分析、信号完整性分析与全芯片功耗分析。

本指南面向使用 PrimeTime 工具进行静态时序与信号完整性分析的工程师。读者应对静态时序分析原理有一定了解。

PrimeTime Suite 文档包括以下文档：
\begin{itemize}
  \item \textit{PrimeTime User Guide}（本用户指南）——使用 PrimeTime、PrimeTime SI、PrimeTime ADV 与 PrimeTime ADVP 工具进行时序分析。
  \item \textit{PrimeECO User Guide}——基于签核质量时序进行 ECO 时序、功耗与 DRC 修复。
  \item \textit{PrimePower User Guide}——静态与动态全芯片功耗分析。
  \item \textit{PrimeShield User Guide}——参数化时序鲁棒性分析、单元鲁棒性分析，以及关键路径快速蒙特卡洛 HSPICE 仿真。
\end{itemize}

Synopsys 文档使用下列约定。

\begin{table}[htbp]
\centering
\caption{文档排版约定}
\begin{tabularx}{\textwidth}{|l|X|}
\hline
\tblhead{约定} & \tblhead{说明} \\
\hline

\cmd{\textbackslash} & 表示命令行续行 \\
\cmd{/} & 表示目录层次 \\
粗体 & 表示带有关联操作的图形用户界面（GUI）元素 \\
Edit $>$ Copy & 表示菜单命令路径，例如打开 Edit 菜单并选择 Copy \\
Ctrl+C & 表示组合键，例如按住 Ctrl 再按 C \\
